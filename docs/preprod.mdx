Preprod is Midnight’s public test network. You will use the same seals as Local desk, but against the published contract. You need a wallet, test tokens, and a working **proof server**. A proof server builds the zero-knowledge proof your wallet needs before it can submit.

## Before you start

1. Two Chrome profiles (one for Lender, one for Borrower). Use the desk **Verifier** role as the third view.
2. Install [Lace](https://chromewebstore.google.com/detail/lace/gafhhkghbfjjkeiennaehnffkwbomagd) or [1AM](https://www.1am.xyz/) and set the network to **Preprod**.
3. Get **tNIGHT** from the faucet. Then generate **tDUST** in the wallet. tDUST pays fees on Preprod.
4. Set the wallet proof server. Release wallets only allow `localhost` or hosts under `*.midnight.network` / `*.1am.xyz`. For many people that means **1AM ProofStation** on Preprod, or Docker on `http://localhost:6300`.

### Local Docker proof server (optional)

```bash
docker run -d -p 6300:6300 midnightntwrk/proof-server:8.0.3 -- midnight-proof-server --network preprod
```

If the browser console shows `localhost:6300` connection refused, either start Docker or point the wallet at an allowed hosted prover such as ProofStation.

## Open the desk

1. Go to [https://tally-jet-mu.vercel.app](https://tally-jet-mu.vercel.app)
2. Stay on **Preprod**
3. Click **Connect Wallet**

Or run locally after compile:

```bash
nvm use 22
npm install
cd contract && compact compile +0.31.1 tally.compact managed/tally
cd .. && npm run dev --workspace leaderboard-ui -- --mode preprod
```

## Join the contract

Paste this address (64 hex characters) and click **Join**:

```
84c44946900ca4ad4456518b09a42c01424dd8b626797310c5ed5b4b933b10af
```

**Deploy** creates a fresh contract if you want your own instance. Share the new address so the Borrower profile can Join the same one.

## Desk ID on Preprod

1. On the Borrower profile: Connect, Join, click **Desk ID**, copy
2. On the Lender profile: Offer → paste that code into **Borrower id**
3. Do not paste a Lace `mn_addr_…` payment address

More detail: [Identity](/docs/identity).

## Loan steps

1. **Lender — Offer** (amount, due, Borrower Desk ID)
2. **Borrower — Accept**
3. **Lender — Disburse** (payment field can hold a Lace payment id when you have one)
4. **Borrower — Repay**
5. **Either — Settle**
6. **Party — Prove standing** (copy the allowlist root)
7. **Verifier — Verify access** → Pass or Fail

## Common errors

| Desk message | What to try |
| --- | --- |
| Set your wallet to Preprod | Switch Lace or 1AM to Preprod |
| Insufficient DUST | Faucet tNIGHT, then generate tDUST |
| Proof server unreachable / Request failed with no popup | Fix wallet prover URI (ProofStation or local Docker on 6300) |
| Contract address must be 64 hex | Fix the Join field |
| This instrument is not addressed to your key | Wrong profile or wrong Desk ID |
| Desk private state is missing | Join again on this desk |
| Allowlist root not in indexer yet | Wait a few seconds and refresh after Prove standing |
