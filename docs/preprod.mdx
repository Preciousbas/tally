Preprod is Midnight’s public test network. You will use the same seals as Local desk, but against the published contract. You need a wallet, test tokens, and a working **proof server**. A proof server builds the zero-knowledge proof your wallet needs before it can submit.

| Network | Midnight Preprod |

## Before you start

1. Two Chrome profiles (one for Lender, one for Borrower). Use **Check a record** as the third view.
2. Install [Lace](https://chromewebstore.google.com/detail/lace/gafhhkghbfjjkeiennaehnffkwbomagd) or [1AM](https://1am.xyz) and set the network to **Preprod**.
3. Get **tNIGHT** from the [Midnight Preprod faucet](https://faucet.preprod.midnight.network/). Then generate **tDUST** in the wallet. tDUST pays fees on Preprod.
4. Set the wallet proof server. Release wallets only allow `localhost` or hosts under `*.midnight.network` / `*.1am.xyz`. For many people that means **1AM ProofStation** on Preprod, or Docker on `http://localhost:6300`.

### Local Docker proof server (optional)

```bash
docker run -d -p 6300:6300 midnightntwrk/proof-server:8.0.3 -- midnight-proof-server --network preprod
```

If the browser console shows `localhost:6300` connection refused, either start Docker or point the wallet at an allowed hosted prover such as ProofStation.

## Open the desk

1. Go to [https://www.tallylend.site](https://www.tallylend.site)
2. Click **Preprod**
3. Click **Connect wallet**. If both Lace and 1AM are installed, choose one. If neither is installed, the page links to the install pages.

Or run locally after compile:

```bash
nvm use 22
npm install
cd contract && compact compile +0.31.1 tally.compact managed/tally
cd .. && npm run dev --workspace leaderboard-ui -- --mode preprod
```

## Use the shared loan book

The public desk loads one shared Preprod contract. You do not need to paste it. Open **Advanced** only to see the 64-character address, copy it, or click **Use shared loan book**.

```
635a4817b625b7954f52b71180da0dbf6c1a50bb538824a3c51fc514e11e77b8
```

Lender and Borrower both use this same address. They do not each create a new book.

## Private ID on Preprod

1. On the Borrower profile: Connect, click **Your private ID**, copy
2. On the Lender profile: Offer → paste that code into **Borrower private ID**
3. Do not paste a Lace `mn_addr_…` payment address

More detail: [Identity](/docs/identity).

## Loan steps

1. **Lender — Offer** (amount, due, Borrower private ID)
2. **Borrower — Accept**
3. **Lender — Send funds** (payment field can hold a Lace payment id when you have one)
4. **Borrower — Repay**
5. **Either — Settle**
6. **Party — Prove good record** (open technical details to copy the allowlist root)
7. **Check a record — Check record** → Pass or Fail

## Common errors

| Desk message | What to try |
| --- | --- |
| Set your wallet to Preprod | Switch Lace or 1AM to Preprod |
| Insufficient DUST | Faucet tNIGHT, then generate tDUST |
| Proof server unreachable / Request failed with no popup | Fix wallet prover URI (ProofStation or local Docker on 6300) |
| Contract address must be 64 hex | Open Advanced and check the address |
| This loan is not addressed to your private ID | Wrong profile or wrong private ID |
| Desk private state is missing | Use the shared loan book again on this desk |
| The root is not visible yet | Wait a few seconds, refresh, then open technical details after Prove good record |
