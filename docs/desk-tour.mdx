The desk is one screen. Mast, help flap, trust strip, mode and role controls, loan list, and the selected loan. Live app: [https://tally-jet-mu.vercel.app](https://tally-jet-mu.vercel.app)

## Local desk vs Preprod

| | Local desk | Preprod |
| --- | --- | --- |
| Label on screen | Demo/Simulator | Midnight Preprod |
| Wallet | None | Lace or 1AM on Preprod |
| Where state lives | Simulator inside the browser | Live Compact contract plus indexer |
| Borrower id field | Hidden (demo keys) | Paste their Desk ID |
| Proof server | Not used | Comes from the wallet settings |

**Local desk** is a practice mode. It runs the same seals without talking to the chain. **Preprod** is Midnight’s public test network.

If the browser finds no Midnight wallet after a few seconds, the desk switches to Local so you can still try the flow.

## Wallets

**Connect Wallet** looks for Lace or 1AM in the browser.

- Lace: [Chrome Web Store](https://chromewebstore.google.com/detail/lace/gafhhkghbfjjkeiennaehnffkwbomagd)
- 1AM: [https://www.1am.xyz/](https://www.1am.xyz/)

You need Connect for Join, Deploy, and every Preprod action. Local desk does not need a wallet.

## Roles

One browser has three roles. Switch the control to match who is acting.

| Role | What they do |
| --- | --- |
| Lender | Offer, Disburse, Settle, Prove standing |
| Borrower | Accept, Repay, Settle, Prove standing |
| Verifier | Paste allowlist root, Verify access → Pass or Fail |

On Preprod, Lender and Borrower are usually two Chrome profiles so each one keeps its own Desk ID secret.

## Trust strip

Under the flap you will see:

- Network name
- Joined contract address (you can copy it)
- **Desk ID** button
- Link to the privacy write-up

On Preprod you **Join** a 64-character contract address or **Deploy** a new one from a connected Lender.
