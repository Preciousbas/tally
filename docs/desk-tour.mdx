The desk is one screen. Mast, help flap, trust strip, mode and role controls, loan list, and the selected loan. Live app: [https://www.tallylend.site](https://www.tallylend.site)

## Local desk vs Preprod

| | Local desk | Preprod |
| --- | --- | --- |
| Label on screen | Demo | Midnight Preprod |
| Wallet | None | Lace or 1AM on Preprod |
| Where state lives | Simulator inside the browser | Live Compact contract plus indexer |
| Borrower field | Hidden (demo keys) | Paste their private ID |
| Proof server | Not used | Comes from the wallet settings |

**Local desk** is a practice mode. It runs the same seals without talking to the chain. **Preprod** is Midnight’s public test network.

A first visit with no saved choice opens on Local desk. The choice is remembered in this browser.

## Wallets

**Connect wallet** looks for Lace and 1AM in this browser.

- One wallet: it connects.
- Both wallets: a chooser lists **1AM Wallet** and **Lace Wallet**.
- Neither wallet: a modal links to [1AM](https://1am.xyz) and [Lace on the Chrome Web Store](https://chromewebstore.google.com/detail/lace/gafhhkghbfjjkeiennaehnffkwbomagd).

You need Connect for Preprod actions. Local desk does not need a wallet. The default contract address loads on its own. The 64-character field and **Use shared loan book** sit behind **Advanced**.

## Roles

One browser has three roles. Switch the control to match who is acting.

| Role | What they do |
| --- | --- |
| Lender | Offer, then Send funds, Settle, and Prove good record once a loan exists |
| Borrower | Accept, Repay, Settle, Prove good record, Prove loans repaid |
| Check a record | Check record, and check a repaid count, → Pass or Fail |

On Preprod, Lender and Borrower are usually two Chrome profiles so each one keeps its own private ID secret.

## Trust strip

Under the flap you will see:

- Demo, or Midnight Preprod
- **Your private ID**
- **Show technical details** (the loan-book address, when you open it)
- A link to the privacy write-up

On Preprod the public desk is one shared contract. It is already loaded. Open **Advanced** only if you need to paste a different 64-character address and click **Use shared loan book**.
