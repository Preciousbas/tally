> Local vs Preprod. Lace or 1AM. Lender, Borrower, and Verifier.

The desk is one screen: mast, flap, trust strip, mode/role toolbar, instrument list, and the selected loan. It is not a dashboard of charts.

Live: [https://tally-jet-mu.vercel.app](https://tally-jet-mu.vercel.app)

## Local desk vs Preprod

| | Local desk | Preprod |
| --- | --- | --- |
| Caption on the desk | Demo/Simulator | Midnight Preprod |
| Wallet | None | Lace or 1AM on Preprod |
| State | `TallySimulator` in the browser | Compact contract + indexer |
| Borrower id field | Hidden — built-in demo keys | Required — paste their Desk ID |
| Proof server | Not used | Wallet-reported prover, typically port 6300 locally |

The toolbar toggle persists in `localStorage` (`tally.deskMode`). If the browser has no compatible wallet after five seconds, the desk switches to Local so you can still run the circuits.

On a narrow viewport, Preprod shows a one-time banner: try Local desk first.

## Wallets

Mast CTA is **Connect Wallet**. The desk enumerates `window.midnight` connectors that satisfy API `4.x`. Display names resolve to **Lace** or **1AM**. It does not hardcode `mnLace`.

Install:

- Lace: [Chrome Web Store](https://chromewebstore.google.com/detail/lace/gafhhkghbfjjkeiennaehnffkwbomagd)
- 1AM: [https://www.1am.xyz/](https://www.1am.xyz/)

Connect is required for Join/Deploy and every Preprod circuit call. Local desk does not need it.

## Roles

One browser, three roles. Switch the segment control. Status hints tell you who acts next.

| Role | Actions |
| --- | --- |
| Lender | Offer, Disburse (Accepted), Settle (Repaid), Prove standing (Settled) |
| Borrower | Accept (Offered), Repay (Funded), Settle (Repaid), Prove standing (Settled) |
| Verifier | Paste allowlist root, **Verify access** → Pass or Fail |

On Preprod, Lender and Borrower are usually two Chrome profiles so each browser holds its own Desk ID secret.

## Trust strip

The strip under the flap shows:

- Network: Midnight Preprod
- Joined contract address (copyable)
- **Desk ID** — this browser's Tally public key, not the wallet address
- Privacy model link

Join / Deploy / Copy sit on the Preprod rail: paste a 64-hex contract address and Join, or Deploy from a connected Lender and share the new address.

## Local desk

Same seals, no wallet. Local instruments are session-only for circuits; the list may restore after refresh, but the simulator must be re-run Offer → Settle before Prove standing if the in-memory tree reset.
