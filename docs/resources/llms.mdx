> llms.txt lists every page for coding agents. Humans use the Use / Build nav.

Tally ships both a Mintlify `docs.json` navigation and [`llms.txt`](/llms.txt). That matches the Aomi split: human tabs can grow; the agent index stays a flat inventory.

When this site is hosted on Mintlify, each MDX page is also served as `.md` at the same path. In git, `.md` mirrors sit next to the `.mdx` source.

## How to use it

- Agents: start at [`docs/llms.txt`](https://github.com/Preciousbas/tally/blob/main/docs/llms.txt)
- Humans: Use tab (desk + concepts) then Build tab (setup + reference)
- Do not treat this page as a second README. Product claims live on the linked pages only
