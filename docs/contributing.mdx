Clone the repo, compile the Compact contract, run tests, then open the desk. GitHub Actions on `main` runs `npm install` and `npm test`.

Midnight-related code in this repository uses the Apache-2.0 license.

## Setup

```bash
git clone https://github.com/Preciousbas/tally
cd tally
nvm use 22
npm install
```

Install Compact 0.31.1:

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/midnightntwrk/compact/releases/latest/download/compact-installer.sh | sh
compact update 0.31.1
```

Compile, test, and run the desk:

```bash
cd contract && compact compile +0.31.1 tally.compact managed/tally && npm test
cd .. && npm run dev --workspace leaderboard-ui -- --mode preprod
```

Open [http://localhost:3000](http://localhost:3000). Use **Local desk** if you want circuits without a wallet.

## Useful commands

```bash
npm install          # Workspaces: contract, api, leaderboard-ui
npm test             # Contract simulator tests
npm run dev          # Desk UI
npm run compile      # compact compile tally.compact
```

## Preview these docs

```bash
npx mint dev --port 3333
```

Port 3333 keeps the desk free on 3000. If Mintlify’s client will not download:

```bash
npm run docs:preview
```

## Deploy

**Desk:** Vercel serves the UI at [https://tally-jet-mu.vercel.app](https://tally-jet-mu.vercel.app).

```bash
npx vercel --prod --yes
```

**Docs:** Import `Preciousbas/tally` in the [Mintlify dashboard](https://mintlify.com). Config lives at the repo root (`docs.json`). Mintlify hosts the docs site. Keep the desk Vercel project pointed at the UI only.

## Pull requests

Match the desk voice. No exclamation marks. No invented product claims. Circuit changes need a simulator test.
