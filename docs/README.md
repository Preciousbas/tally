# Tally documentation

Mintlify docs-as-code. Pages are MDX in this folder. Config lives at the repo root (`docs.json`, `mint.json`).

## Preview

```bash
npx mint dev --port 3333
```

Fallback HTML preview:

```bash
npm run docs:preview
```
