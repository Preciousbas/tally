---
title: Local quickstart
description: Finish the full loan path in about ten minutes with no wallet.
---

By the end you will Offer, Accept, Disburse, Repay, and Settle a loan in the browser, then Prove standing and see Verifier **Pass**. Amount never shows on the instrument row.

This path does not use Midnight Preprod. For the live test network, open the [Preprod guide](/docs/preprod).

## Before you start

- Node 22 (`nvm use 22`)
- npm
- A Chromium browser (Chrome, Edge, Brave, and similar)

You do not need Compact for Local desk. The page runs a simulator. Compile and `npm test` only if you want the same circuits checked as code first.

## 1. Install and open the desk

```bash
git clone https://github.com/Preciousbas/tally
cd tally
nvm use 22
npm install
npm run dev --workspace leaderboard-ui -- --mode preprod
```

Open [http://localhost:3000](http://localhost:3000). Or use the hosted desk at [https://tally-jet-mu.vercel.app](https://tally-jet-mu.vercel.app).

## 2. Switch to Local desk

Click **Local desk** in the toolbar. The caption should read Demo/Simulator.

If no Lace or 1AM wallet is installed, the desk may switch to Local on its own.

## 3. Offer as Lender

Stay on **Lender**.

1. Amount: a whole number greater than 0 (for example `50`)
2. Due in days: `30` or leave blank (defaults to 30)
3. Click **Offer**

A row `#1` appears with seal **Offered**. Amount reads **off-ledger**.

![Local offered instrument.](/docs/screenshots/local/01-offered.png)

## 4. Accept as Borrower

Switch the role to **Borrower**. Click **Accept**. Seal becomes **Accepted**.

## 5. Disburse as Lender

Switch to **Lender**. Payment may stay empty on Local desk. Click **Disburse**. Seal becomes **Funded**.

![Local funded instrument.](/docs/screenshots/local/02-funded.png)

## 6. Repay and Settle

1. Borrower → **Repay** → **Repaid**
2. Lender or Borrower → **Settle** → **Settled**

![Settled, Prove standing enabled.](/docs/screenshots/local/03-settled-prove.png)

## 7. Prove standing

As Lender or Borrower, click **Prove standing**. You should see **Standing confirmed** and a copyable allowlist root.

![Standing confirmed on Local desk.](/docs/screenshots/local/04-standing-confirmed.png)

## 8. Verifier Pass

Switch to **Verifier**. Click **Verify access**. Standing seal: **Pass**.

![Verifier Pass — yes or no only.](/docs/screenshots/local/05-verifier-pass.png)

## If something fails

| What you see | What to try |
| --- | --- |
| Amount error | Use a whole number greater than 0 |
| Local simulator reset | Refresh cleared memory. Run Offer through Settle again |
| Standing Fail | Finish Settle first, or paste the root from a fresh Prove standing |
| Empty list after refresh | Offer through Settle again before proving |
