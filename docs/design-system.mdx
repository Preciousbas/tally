> Warm ledger desk. Fraunces, Figtree, oxblood. Not a default SaaS kit.

Tally is archival trade-credit on Midnight, not a crypto casino. The canonical file is [`DESIGN_SYSTEM.md`](https://github.com/Preciousbas/tally/blob/main/DESIGN_SYSTEM.md) at the repo root. This page is the contributor summary. If copy or color drifts, the root file wins.

## Brand core

A medieval tally stick was split down the grain. Creditor kept one half, debtor the other. Forgery failed because the wood had to match. Tally does that on Midnight: the public ledger holds the matching grain. Amount and names live only in the two private halves.

Product name: **Tally**. Repo: `tally-midnight`. Mascot: Notch (the split stick). Logo: `brand/tally-stick.svg` — vertical stick, five notches, hairline gap. Favicon is the stick.

Headline on the desk: `The other half stays private.` How-it-works is the ledger flap `How a stick is cut`, never a route or a modal.

## Type

- Display: **Fraunces** (opsz, soft) — headlines
- Body: **Figtree** — UI, forms, this docs body
- Eyebrows: Figtree 600, letter-spacing 0.18em, uppercase

Do not use Inter, Roboto, or Space Grotesk.

## Button laws

- Primary: oxblood fill, bone text, hover `scale(0.97)`
- Secondary: transparent, bone border
- Never `scale(1.02)` or grow

## Motion

Desk actions are high frequency. Connect, Deploy, Preprod/Local, loan list, Offer / Accept / Repay / Settle: no animation, or ≤180ms. Purposeful motion is reserved for the grain flap, the Funded seal on status change, and Copied feedback. Cap UI transitions at 300ms. Keyboard-initiated actions: zero delay.

## Rejection list

No gradient text. No purple neon. No glassmorphism. No pure white or black. No exclamation marks. No seamless / robust / empower / unlock / supercharge. No three-column feature grids. No “unlock credit”. The product is a desk of instruments, not a dashboard.

Do not bulk-install shadcn or generic dashboard kits into `leaderboard-ui`. Map any new token to the CSS variables above.
