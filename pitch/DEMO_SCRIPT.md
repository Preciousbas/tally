# Demo video script (under 2 minutes)

Start: "This is Tally for the Midnight Buildathon."

Required for Level 2 judges: **wallet connect** and **at least one successful circuit call**, linked from README `## Demo`.

0:00–0:15 Stick on screen. "A tally stick was split down the grain. We originate a loan the same way. Terms stay private. The chain keeps the matching grain."

0:15–0:25 Connect Lace (or 1AM) on Preprod or show Local desk after naming that Lace is used on Preprod. Desk.

0:25–0:40 Lender: amount 50, due 30, Offer. Point at instrument: status Offered, Amount off-ledger. Explorer cannot see how much.

0:40–0:55 Switch to Borrower profile. Accept.

0:55–1:15 Lender: paste Preprod tx id (or Local desk Disburse). Funded seal.

1:15–1:35 Borrower Repay. Settle. Status Settled. How a stick is cut: Offer through Settle. Amount stayed private.

1:35–1:55 Prove standing. Switch Verifier. Verify access shows Pass. They never see amount or which leaf.

Upload publicly (Loom / YouTube unlisted / Drive anyone-with-link). Paste the URL into README under `## Demo` and into the Level 2 form.

Do not use exclamation marks. Name the program in the first sentence.
